# ART TUNING — Премиальный сайт автоателье (Красноярск)

Современный, премиальный digital-продукт для автоателье **ART TUNING** в Красноярске, специализирующегося на перетяжке, ремонте, восстановлении и индивидуальном тюнинге автомобильных интерьеров.

Дизайн разработан в эстетике ведущих мировых автомобильных брендов (Porsche Exclusive Manufaktur, Mercedes-AMG, Apple) с акцентом на архитектуру, визуальную иерархию, свободное пространство и кинематографичный UX/UI.

---

## 🌟 Ключевые возможности проекта

1. **Кинематографичный главный экран (Hero):**
   - Утверждённые заголовки: *«Искусство преображения автомобильного интерьера»*, *«Перетяжка, восстановление и индивидуальный дизайн автомобильных салонов»*.
   - Кнопки быстрого действия: «Обсудить проект» и «Наши работы».
   - Официальный рейтинг 5.0 на Яндекс Картах, геометка Красноярска (ул. Шахтёров, 4, стр. 3).
   - Плавное появление, микроанимации и статус работы в реальном времени.

2. **О компании:**
   - Честное и убедительное позиционирование: заводские стандарты, безопасность SRS Airbag, оригинальные европейские кожи.

3. **Каталог услуг с модальными карточками:**
   - 4 направления: *Перетяжка салона*, *Ремонт и восстановление*, *Комфорт и подогревы*, *Детейлинг*.
   - Каждая услуга содержит подробное модальное окно: этапы работ, гарантия, сроки, рекомендуемые материалы и кнопка прямого перехода в конфигуратор.

4. **Интерактивный конфигуратор стоимости (Ключевой модуль):**
   - **Этап 1:** Выбор класса авто, марки, модели и года выпуска.
   - **Этап 2:** Мультивыбор услуг (руль, кресла, потолок Alcantara, дверные карты, торпедо, подогревы, боковины).
   - **Этап 3:** Выбор материалов с тактильными образцами: Натуральная Nappa, Alcantara, Dakota/Monza, Экокожа Schweizer.
   - **Этап 4:** Настройка узора отстрочки (классика, ромб AMG, полосы GT, соты RS), цвета нитей, перфорации, нулевой метки и тиснения.
   - **Этап 5:** Мгновенный динамический расчёт сметы с честной пометкой о демонстрационном характере и подтверждении мастером.
   - **Этап 6:** Отправка конфигурации мастеру с прикреплением фотографий салона.

5. **Интерактивное портфолио Before / After:**
   - Полноценные слайдеры сравнения состояния элементов «До» и «После» (руль Porsche Macan, кресло Mercedes-AMG).
   - Фильтрация по категориям и полноэкранный Lightbox для просмотра фото в высоком разрешении.

6. **Каталог премиум-материалов:**
   - Детальный разбор Nappa, оригинальной Alcantara (Италия), Dakota и экокожи на микрофибре.
   - Цветовая палитра с артикулами и техническими параметрами (тест Мартиндейла, паропроницаемость, происхождение).

7. **Отзывы с Яндекс Карт:**
   - Реальные отзывы владельцев с рейтингом 5.0 и прямым переходом в официальную карточку организации.

8. **Архитектура интеграции с Telegram Bot API:**
   - Готовый модуль `src/utils/telegram.ts`.
   - Если токен не задан, сайт не имитирует ложный успех, а вежливо объясняет статус подключения и предлагает прямую отправку в WhatsApp мастера или быстрый звонок.

9. **Контакты и интерактивная карта:**
   - Адрес: г. Красноярск, ул. Шахтёров, 4, строение 3.
   - Телефоны: `+7 (391) 282-35-04`, `+7 (902) 982-35-04` с быстрым копированием и вызовом.
   - Интерактивная карта с ночным премиум-стилем и кнопка построения маршрута в Яндекс Навигаторе.

## 🛠 Технологический стек

- **Фреймворк:** React 19 + TypeScript
- **Сборщик:** Vite
- **Стилизация:** Tailwind CSS (кастомная палитра `art-*`, glassmorphism, эффекты свечения)
- **Иконки:** Lucide React
- **Анимации:** CSS Transitions, Framer Motion, Backdrop Blur
- **SEO & Семантика:** Schema.org `AutoBodyShop`, OpenGraph, микроразметка гео-координат

## ⚙️ Настройка Telegram Bot API

Для получения заявок прямо в Telegram владельца бизнеса:
1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Узнайте ваш Chat ID через [@userinfobot](https://t.me/userinfobot).
3. Создайте файл `.env` в корне проекта (по примеру `.env.example`):
```env
VITE_TELEGRAM_BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
VITE_TELEGRAM_CHAT_ID=123456789
```
4. Перезапустите сервер разработки. Заявки с сайта и интерактивного конфигуратора начнут поступать в Telegram в реальном времени.
